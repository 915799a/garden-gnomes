# 🍄 정원 요정 날리기 (Garden Gnomes)

구글 두들의 명작 기념 게임 **정원 요정(Celebrating Garden Gnomes)** 스타일의 경쾌하고 아기자기한 웹 캐주얼 게임입니다.  
클로드(Claude)가 제작한 순수 HTML5 Canvas 기반 단일 파일 게임으로, PC와 모바일 환경 모두에서 부드럽게 플레이할 수 있습니다.

## 🎮 게임 특징
- **투석기 타이밍 발사**: 타이밍 게이지를 맞춰 최적의 각도와 폭발적인 파워로 정원 요정을 공중으로 날려보내세요.
- **물리 비행 & 급강하 부스트**: 비행 중 화면을 클릭/터치하면 강력한 급강하 부스트(Slam)가 발동되어 바운스 오브젝트를 전략적으로 노릴 수 있습니다.
- **정원 인터랙티브 요소**:
  - 🍄 **버섯**: 하늘 높이 튕겨 오르는 슈퍼 바운스
  - 🌈 **무지개** / ☁️ **구름**: 공중 가속 부스트
  - 🦋 **나비**: 공중 가속 및 부스트 게이지 1회 즉시 충전
  - 🪵 **통나무** / 🪨 **돌**: 부딪히면 감속 및 방해
  - 🌼 **꽃밭 연출**: 요정이 지나간 길과 바운스한 지점에 알록달록한 꽃이 피어납니다.
- **업그레이드 & 요정 캐릭터**:
  - 비행 거리와 꽃 점수로 획득한 밤(🌰)을 모아 투석기 파워, 버섯 반발력, 부스트 횟수 강화
  - 고유 능력을 지닌 4종의 요정 모자(빨강, 파랑, 초록, 황금) 해금
- **로컬 기록 저장**: 최고 비행 거리(m) 자동 저장
- **Web Audio 효과음**: 발사, 바운스, 급강하, 아이템 획득, 착지 사운드 완비

## 🕹️ 조작 방법
- **발사**: 화면 클릭 / 스페이스바 / 모바일 터치
- **비행 중 부스트**: 화면 클릭 / 스페이스바 / 모바일 터치 (잔여 부스트 게이지 소모)
- **메뉴 & 업그레이드**: 마우스 클릭 또는 터치
